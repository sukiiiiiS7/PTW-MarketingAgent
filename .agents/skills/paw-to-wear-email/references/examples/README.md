# Approved Email Examples — VISUAL / LAYOUT REFERENCE ONLY

The user identified these emails as satisfactory **visual and layout references**.

## Allowed use

Use these files only to understand Paw to Wear's email presentation grammar, such as:
- 600px canvas and overall proportions;
- whitespace and section spacing;
- headline/body visual hierarchy;
- warm neutral surfaces and subtle borders;
- button treatment;
- image/card proportions;
- mobile stacking behavior;
- visual restraint and density.

## Prohibited use

Do **not** use these examples as content templates or strategy templates.

Do not inherit or copy:
- subject/preheader;
- headline or body wording;
- narrative angle;
- section sequence;
- number of sections;
- customer-story structure;
- process/proof structure;
- CTA wording;
- offer placement;
- product facts, prices, discounts, codes, or URLs;
- Klaviyo variable paths or dynamic-content syntax.

The historical dynamic syntax in an example is historical implementation evidence only, not a verified runtime schema for a new email. Dynamic variables must be validated independently under `references/klaviyo/`.

**Image rule:** examples contain real historical image URLs for visual reference only. Never copy those static image URLs into newly generated emails. Convert visual positions into labeled placeholders.

Priority:
1. current user brief;
2. current Brand Brief;
3. verified Product Truth / task-local facts;
4. current email/Klaviyo rules;
5. examples for visual/layout styling only.

Files:
